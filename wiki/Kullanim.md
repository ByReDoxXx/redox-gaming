# Kullanım

## Ekranlar

**Ana ekran: platform carousel.** Üstte RedoX logosu, altında sağa sola kayan sistemler var. Seçili sistem büyük, bir piksel kaidenin üstünde ve kendi renginde parlıyor. Altında adı, kaç oyununuz olduğu ve ücretsiz oyun olup olmadığı yazar.

**Platform ekranı.** İki sekme ve bir düğme:

- **OYUNLARIM:** bu sistem için sahip olduğunuz oyunlar, kapak resimleriyle.
- **ÜCRETSİZ OYUNLAR:** tek tuşla indirebileceğiniz yasal homebrew oyunlar. Bkz. [Ücretsiz Oyunlar](Ucretsiz-Oyunlar).
- **+ KLASÖR EKLE:** bir klasörü ya da USB belleği tarar. Bkz. [Oyun Ekleme](Oyun-Ekleme).

**Oyun.** Görüntü, sistemin gerçek en-boy oranıyla tam sayı katlarında büyütülür; pikseller keskin kalır.

## Kontroller

| İşlem | Klavye | Gamepad |
|---|---|---|
| Gezinme / seçme | Yön tuşları | Yön tuşu veya sol çubuk |
| Menüde onay | `Enter` | alt düğme (Xbox A / PlayStation ✕) |
| Geri | `Esc` · Android geri | sağ düğme (Xbox B / ○) |
| Sekme değiştir | `Q` / `E` | LB / RB |
| Oyunda A / B | `X` / `Z` | sağ / alt düğme |
| Oyunda X / Y | `S` / `A` | üst / sol düğme |
| Oyunda L / R | `Q` / `W` | LB / RB |
| Oyunda Start / Select | `Enter` / `Shift` | Start / Back |
| Duraklatma menüsü | `Esc` | Select + Start ya da Guide |
| Hızlı kaydet / yükle | `F2` / `F4` | duraklatma menüsü |

Oyundaki düğmeler SNES düzenine **konuma göre** eşlenir: kumandanızın üstünde ne yazarsa yazsın, oyunun A'sı her zaman sağdaki düğmedir. İki gamepad desteklenir (1. ve 2. oyuncu).

## Duraklatma menüsü

Oyun sırasında `Esc`'e (ya da Select + Start'a) basın:

| Seçenek | Ne yapar |
|---|---|
| DEVAM ET | oyuna döner |
| DURUMU KAYDET | durum kaydı: o anı olduğu gibi dondurur |
| DURUMU YÜKLE | kaydedilen anı geri yükler |
| SIFIRLA | konsolu sıfırlar |
| KÜTÜPHANEYE DÖN | platformun oyun listesine döner |

Her oyun için bir durum kaydı yeri vardır. **Pil kayıtları** (pilli kartuştaki gibi oyun içi kayıtlar) oyundan çıkarken otomatik yazılır.

## Fare ve dokunmatik

Her şey fareyle (tıklama, carousel için tekerlek) ve dokunmatikle (carousel'i kaydırma, kartlara dokunma) de çalışır. Telefonlar için ekran üstü oyun kontrolleri yol haritasında.
