# Using RedoX Gaming

## Screens

**Home: platform carousel.** The RedoX logo sits on top; below it the systems slide left and right. The selected system is large, on a pixel pedestal, with a glow in its colour. Under it: the name, how many games you have, and whether free games exist.

**Platform screen.** Two tabs and one button:

- **OYUNLARIM** (my games): the games you have for this system, with box art.
- **ÜCRETSİZ OYUNLAR** (free games): legal homebrew you can download with one button. See [Free Games](Free-Games).
- **+ KLASÖR EKLE** (add folder): scan a folder or USB stick. See [Adding Games](Adding-Games).

**Game.** The picture is scaled by whole numbers with the system's real aspect ratio, so pixels stay sharp.

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move / choose | Arrow keys | D-pad or left stick |
| Confirm in menus | `Enter` | bottom face button (Xbox A / PlayStation ✕) |
| Back | `Esc` · Android back | right face button (Xbox B / ○) |
| Switch tabs | `Q` / `E` | LB / RB |
| In game: A / B | `X` / `Z` | right / bottom face button |
| In game: X / Y | `S` / `A` | top / left face button |
| In game: L / R | `Q` / `W` | LB / RB |
| In game: Start / Select | `Enter` / `Shift` | Start / Back |
| Pause menu | `Esc` | Select + Start, or Guide |
| Quick save / quick load | `F2` / `F4` | pause menu |

In-game buttons follow the SNES layout **by position**: the game's A is always the right-hand button, whatever is printed on your pad. Two gamepads are supported (player 1 and player 2).

## Pause menu

Press `Esc` (or Select + Start) during a game:

| Item | What it does |
|---|---|
| DEVAM ET | back to the game |
| DURUMU KAYDET | save state: freezes the exact moment |
| DURUMU YÜKLE | load that saved moment |
| SIFIRLA | reset the console |
| KÜTÜPHANEYE DÖN | back to the platform's game list |

There is one save-state slot per game. **Battery saves** (in-game saves, like a cartridge with a battery) are written automatically when you leave the game.

## Mouse and touch

Everything also works with a mouse (click, wheel to turn the carousel) and touch (swipe the carousel, tap cards). On-screen game controls for phones are on the roadmap.
