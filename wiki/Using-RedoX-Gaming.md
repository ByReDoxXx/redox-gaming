# Using RedoX Gaming

## Screens

**Home: platform carousel.** The RedoX logo sits on top; below it the systems slide left and right. The selected system is large, on a pixel pedestal, with a glow in its colour. Under it: the name, how many games you have, and whether free games exist.

- **Recently played** (clock) and **Favourites** (star) lead the carousel once they have games. They list games from every system.
- **Y** (keyboard `C`) continues the last game you played, straight from the home screen.
- **START** (keyboard `S` or `F1`) or the gear in the top right corner opens **Settings**.
- When a newer version is published on GitHub, a gold **NEW VERSION** badge appears in the top left corner.

**Platform screen.** Two tabs and three buttons:

- **MY GAMES**: the games you have for this system, with box art, play time and when you last played.
- **FREE GAMES**: legal homebrew you can download with one button. See [Free Games](Free-Games).
- **SEARCH** (pad Y, keyboard `/`): type part of a name; the list filters as you type.
- **SORT** (pad Select, keyboard `O`): A-Z, last played, most played.
- **+ ADD FOLDER**: scan a folder or USB stick. See [Adding Games](Adding-Games).

Press **X** (keyboard `F`) on a game to add it to (or remove it from) your favourites. Favourites carry a gold star.

**Game.** The picture size and filter come from Settings: pixel perfect (default), fit to screen or stretch; no filter, CRT TV, LCD handheld or smooth.

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move / choose | Arrow keys | D-pad or left stick |
| Confirm in menus | `Enter` | bottom face button (Xbox A / PlayStation ✕) |
| Back | `Esc` · Android back | right face button (Xbox B / ○) |
| Switch tabs | `Q` / `E` | LB / RB |
| Favourite / search / sort | `F` / `/` / `O` | X / Y / Select |
| Continue last game (home) | `C` | Y |
| Settings (home) | `S` or `F1` | Start |
| In game: A / B | `X` / `Z` | right / bottom face button |
| In game: X / Y | `S` / `A` | top / left face button |
| In game: L / R | `Q` / `W` | LB / RB |
| In game: Start / Select | `Enter` / `Shift` | Start / Back |
| **Rewind** (hold) | `R` | left trigger (LT / L2) |
| **Fast forward** (hold) | `Space` | right trigger (RT / R2) |
| Pause menu | `Esc` | Select + Start, or Guide |
| Quick save / quick load (slot 1) | `F2` / `F4` | pause menu |

In-game buttons follow the SNES layout **by position**: the game's A is always the right-hand button, whatever is printed on your pad. Two gamepads are supported (player 1 and player 2). All keys and buttons can be changed in **Settings → Controls**.

On PlayStation games the triggers are L2/R2 of the game, so rewind and fast forward use the keyboard only.

## Pause menu

Press `Esc` (or Select + Start) during a game:

| Item | What it does |
|---|---|
| CONTINUE | back to the game |
| SAVE STATE | freeze this exact moment in one of **4 slots**; each slot shows a picture and the date |
| LOAD STATE | go back to a saved moment |
| CHEATS | turn cheat codes on and off, add your own or search the cheat database |
| ACHIEVEMENTS | your RetroAchievements for this game (when signed in) |
| RESTART | reset the console and forget where you left off |
| BACK TO LIBRARY | back to the game list (your place is saved) |

**Resume where you left off:** when you leave a game, its exact state is saved automatically and loaded the next time you start it. Turn it off in Settings if you prefer to always start fresh. **Battery saves** (the game's own saves, like a cartridge with a battery) are written as before.

## Rewind and fast forward

Hold the left trigger (keyboard `R`) to run the game backwards, up to about a minute; let go to play on from there. Hold the right trigger (keyboard `Space`) to run at x2–x8 speed (Settings → Fast forward speed). Rewind can be turned off in Settings, and is off in hardcore mode.

## Cheats

Pause → **CHEATS**:

- **SEARCH CHEAT DATABASE** looks the game up in the [libretro-database](https://github.com/libretro/libretro-database) cheat collection (matched by the file name, like the box art) and adds what it finds, switched off.
- **+ ADD CODE** for your own Game Genie, Action Replay, GameShark or raw codes.
- Select a cheat to switch it on or off; **DELETE** removes it.

Cheats are saved per game. Whether a code works depends on the emulator core.

## Settings

| Section | Settings |
|---|---|
| General | language (Türkçe / English), volume, menu sounds, animated background, fullscreen (PC) |
| Video | picture size, filter |
| Gameplay | resume where you left off, rewind, fast forward speed, on-screen gamepad (auto / on / off) |

| Library | added folders (remove a folder) |

## Mouse and touch

Everything also works with a mouse (click, wheel to turn the carousel) and touch (swipe the carousel, tap cards). On phones and tablets an **on-screen gamepad** appears during games: D-pad, the platform's face buttons, L/R where needed, Start/Select, and pause / rewind / fast forward at the top. It hides when a gamepad is connected (Settings → On-screen gamepad).
