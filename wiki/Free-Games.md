# Free Games

The **ÜCRETSİZ OYUNLAR** (free games) tab is a small store of **homebrew**: new games made for old consoles by today's developers and shared for free.

## How it works

1. Open a system → **ÜCRETSİZ OYUNLAR**.
2. Pick a game: you see a screenshot, the developer, the year, the number of players and a description.
3. Press **İNDİR VE OYNA** (download and play). The game downloads, the system's core downloads if it is the first time, and the game starts.
4. The game now also appears under **OYUNLARIM** with its screenshot as cover.

## Where the games come from

The list comes from **[Retrobrews](https://retrobrews.github.io)**, a project that collects free homebrew for emulators. Retrobrews keeps one GitHub repository per system and states that every listed game was approved for sharing by its owner. RedoX Gaming shows the developer and the source on every game. If you are a developer and want a game removed, please contact Retrobrews and [open an issue](https://github.com/ByReoxXx/redox-gaming/issues) here too.
